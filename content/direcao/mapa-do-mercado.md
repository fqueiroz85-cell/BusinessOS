## Como é o mercado em que você vai competir?

### Perguntas para refletir

- Qual é o tamanho estimado desse mercado (TAM/SAM/SOM), mesmo que seja uma estimativa grosseira?
- Quem são os 3 a 5 principais concorrentes diretos? O que cada um faz bem e mal?
- Existem concorrentes indiretos (alternativas "caseiras", planilhas, não fazer nada) que competem pela atenção do cliente?
- O mercado está crescendo, estável ou encolhendo? O que está mudando nele agora (tecnologia, regulação, comportamento)?
- Onde você pretende entrar: um nicho desatendido, um segmento de preço específico, uma geografia?

### Framework: TAM / SAM / SOM

| Camada | Definição | Sua estimativa |
|---|---|---|
| TAM | Todo o mercado possível para essa categoria de solução | |
| SAM | Fatia que seu modelo de negócio consegue efetivamente alcançar | |
| SOM | Fatia realista que você pode capturar nos próximos 12 meses | |

### Checklist

- [ ] Cada estimativa tem pelo menos uma fonte externa (não só opinião pessoal)
- [ ] Identifiquei concorrentes diretos E indiretos (incluindo "não fazer nada")
- [ ] Sei se o mercado está aquecendo, estável ou encolhendo, e por quê
- [ ] Escolhi um ponto de entrada específico (nicho, geografia ou faixa de preço)
